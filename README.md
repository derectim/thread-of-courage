# Нитка храбрости

Играбельная вертикальная версия авторской браузерной аркады. Эля Штопка зашивает ожившие кошмары светящимися иглами: нужно попадать в свободные места вращающейся цели и не задевать уже закреплённые иглы.

## Что уже работает

- управление кликом, касанием или клавишей `Пробел`;
- точная угловая проверка столкновения игл;
- девять последовательных противников: по два монстра и одному боссу в комнате;
- три комнаты: чердак, кукольный театр и сердце швейной машины;
- четыре состояния повреждения каждого босса, меняющиеся по ходу боя;
- мастерская между боями с четырьмя улучшениями до пятого уровня;
- немедленный переход в мастерскую после каждого поражения;
- двойной стежок, точность, скорость иглы и спасительные щиты;
- сдержанная экономика: 2 нити за обычного врага и 3 за босса;
- победа, поражение, новые походы и двухфазные боссы;
- локальное сохранение нитей, улучшений, лучшего этапа и настройки звука;
- процедурные звуки без сторонних аудиофайлов;
- адаптивный портретный экран для компьютера и телефона;
- оригинальные сгенерированные героиня с оружием, три босса и три фона.

Исходные PNG хранятся в `assets/source-art`, а оптимизированные игровые WebP — в `public/assets/art`.

## Запуск

Онлайн-версия для телефона, планшета и компьютера:
[derectim.github.io/thread-of-courage](https://derectim.github.io/thread-of-courage/).

Самый простой способ на Windows — дважды щёлкнуть файл `Играть.cmd` в корне проекта. Он запустит локальный сервер и сам откроет браузер.

Либо выполните команды ниже:

```powershell
npm install
npm run dev
```

После запуска откройте `http://localhost:5173/`.

## Проверка и сборка

```powershell
npm test
npm run build
```

Готовая статическая версия появится в папке `dist`.

Каждый push в ветку `main` автоматически проверяет, собирает и публикует игру
через GitHub Pages.
